# USER & DEVELOPER MANUAL
## AI Chatbot Using Natural Language Processing (NLP)

This manual guides end-users, students, instructors, and developers on how to operate, configure, test, and extend the AI Chatbot application.

---

## 1. USER GUIDE (HOW TO USE THE CHATBOT)

### 1.1 Accessing the Application
1. Start the Flask application as described in Section 2.
2. Open your web browser and visit: `http://127.0.0.1:5000`
3. You will be greeted by the **Cognevance NLP** dark-themed interface with an online status indicator.

### 1.2 Interacting with the Chatbot
- **Typing a Question**: Type your question in the input bar at the bottom and press `Enter` or click the paper airplane send button.
- **Smart Suggested Questions (Feature A)**:
  - When the chat page opens, a row of suggested starter question chips appears above the input box (e.g., *"What is Artificial Intelligence?"*, *"Explain Natural Language Processing"*).
  - Simply click on any suggestion chip: the query is automatically populated and sent immediately!
- **Understanding Bot Metadata**:
  - Below each chatbot response, inspect the detected intent tag (e.g., `machine_learning`) and the confidence score (e.g., `88% conf`).
  - If the question is outside the chatbot's domain, the bot displays a helpful `Fallback` badge.

### 1.3 Exporting Conversation History (Feature C)
1. In the top right of the chat header, click the **Export History** dropdown button.
2. Select either:
   - **Export as JSON**: Downloads a structured `.json` file containing message records, roles, timestamps, and predicted intent metadata.
   - **Export as Plain Text**: Downloads a clean `.txt` readable transcript suitable for academic submission or archiving.

### 1.4 Clearing the Conversation
- Click the red **Clear Chat** button in the header.
- Confirm the dialog to reset your conversation session history.

### 1.5 Viewing the Analytics Dashboard (Feature B)
- In the left sidebar navigation, click on **Analytics Dashboard** (or navigate to `http://127.0.0.1:5000/dashboard`).
- The dashboard displays:
  - **Live Counters**: Total messages exchanged, number of user queries, average confidence percentage, and fallback rate.
  - **Offline Model Evaluation Metrics**: Real test set Accuracy, Precision, Recall, and F1-Score.
  - **Intent Distribution Chart**: Bar chart highlighting the most frequently asked intent categories.
  - **Reliability Chart**: Doughnut chart showing the proportion of confident predictions vs. fallback queries.
  - **Confusion Matrix**: Visual 21-class confusion matrix generated by Scikit-learn.
  - **Live Query Telemetry Feed**: Table listing recent user queries, detected intents, and confidence ratings.

## 2. DEVELOPER GUIDE (INSTALLATION & EXECUTION)

### 2.1 Environment Setup
Ensure Python 3.10 or higher is installed:
```bash
python --version
```

Clone the repository and install all required packages:
```bash
pip install -r requirements.txt
```

Download the required NLTK corpora:
```bash
python -c "import nltk; nltk.download('punkt'); nltk.download('punkt_tab'); nltk.download('wordnet'); nltk.download('omw-1.4'); nltk.download('stopwords')"
```

### 2.2 Model Training & Evaluation
To retrain the model and regenerate all evaluation reports and plots:
```bash
python nlp/train.py
```
This script will:
1. Parse all patterns from `data/intents.json`.
2. Apply the text preprocessing pipeline.
3. Perform an 80/20 stratified split.
4. Fit the TF-IDF vectorizer and Multinomial Logistic Regression model.
5. Save the trained artifact to `models/chatbot_model.pkl`.
6. Compute performance metrics and save `results/evaluation_report.txt`, `results/metrics.json`, and `results/confusion_matrix.png`.

### 2.3 Running the Application
```bash
python app.py
```
By default, the server starts on `http://127.0.0.1:5000`.

## 3. HOW TO EXTEND THE CHATBOT

### 3.1 Adding a New Intent
To add a new topic or domain (e.g., `cloud_computing` or `blockchain`):
1. Open `data/intents.json`.
2. Append a new intent object to the `"intents"` list:
   ```json
   {
     "tag": "blockchain_basics",
     "patterns": [
       "What is blockchain?",
       "Explain distributed ledger technology",
       "How do smart contracts work?",
       "What is cryptocurrency mining?",
       "Tell me about blockchain consensus"
     ],
     "responses": [
       "Blockchain is a decentralized, distributed, and immutable ledger that securely records transactions across a network of peer-to-peer computers.",
       "Smart contracts are self-executing agreements with the terms of the contract directly written into lines of code on the blockchain."
     ]
   }
   ```
3. Re-run model training:
   ```bash
   python nlp/train.py
   ```
4. Restart `app.py`. The chatbot will immediately understand the new intent with full confidence!

## 4. RUNNING AUTOMATED TESTS

Run the complete test suite with verbose reporting:
```bash
python -m pytest -v
```

To run a specific test suite:
```bash
# Test preprocessing only
python -m pytest tests/test_preprocessing.py -v

# Test chatbot inference & confidence only
python -m pytest tests/test_chatbot.py -v

# Test Flask REST endpoints only
python -m pytest tests/test_app.py -v
```

## 5. TROUBLESHOOTING

| Issue | Cause | Solution |
|:---|:---|:---|
| `Address already in use (Port 5000)` | Another process is using port 5000 | Kill the process using port 5000 or change port in `app.py` to `port=5001`. |
| `Resource punkt not found` | Missing NLTK corpora download | Run the one-time NLTK download command listed in Section 2.1. |
| `Model file not found` | `models/chatbot_model.pkl` missing | Run `python nlp/train.py` to train and serialize the model. |
| `Low confidence / fallback on valid query` | Query has no overlap with training vocabulary | Add 2–3 example variations of that phrasing into `data/intents.json` and retrain. |
